下のピアノ鍵盤をタップして音符を入力してください(白鍵/黒鍵をそのままタップすればOK。♯♭ボタンで押してから鍵盤を押す方法もあります)。置いた音符は上下にドラッグすると音の高さを直せます(タップで選ぶと音価や♯♭も直せます)。拍子・調号は曲の途中でも変更できますが、譜面全体に適用されます(1曲=1拍子・1調のシンプルな運用)。「⋃ タイ」で選択中の音符と直後の同じ高さの音符をつなげます。PCではキーボード入力(A〜G:新規音符 / 1〜7:音価 / .:付点 / -,=,0:♭♯♮ / ←→:音符移動 / ↑↓:半音移動 / Delete:削除 / Ctrl+Z:取り消し。詳しい一覧は❓から)やMIDIキーボード(対応ブラウザのみ、上のボタンでオン)も使えます。「🎶 和音」ボタンで和音入力に切り替えられます(選択中の音符にタップした音を追加、既に入っている音をもう一度タップすると削除。上書きではなく足し引きなので、単音モードとは挙動が違います。次の和音に移る時は→キーやEscapeで選択を外してください)。
